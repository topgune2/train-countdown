# つぎ何分？ - 電車カウントダウン

指定した駅の **「どっち方向か」「次の電車まであと何分か」「その次の電車まであと何分か」** だけをブラウザで瞬時に表示するWebアプリです。

## 特徴

1. **端末ごとに駅を記憶（毎回検索不要）**
   - ブラウザの `localStorage` と `Cookie` の二重保存により、スマホ・PC・タブレットなど端末ごとに異なる駅・路線を登録できます。
   - 2回目以降はリンクを開くだけで **0.1秒でカウントダウン画面** が表示されます。
2. **ネットから時刻表を自動取得 & ダイヤ改正に自動追従**
   - 駅名を検索して路線を選ぶだけで、ネット（Yahoo!路線情報）から **平日・土曜・日曜祝日** の時刻表データを自動取得してキャッシュします。
   - 前回の取得から14日経過した時や、**ダイヤ改正時期（3月・10月）** になると、ページを開いた際に裏側で自動的に最新の時刻表を再取得して更新します（手動の「🔄 ダイヤ更新」ボタンもあり）。
3. **日本の祝日・深夜帯（24時以降）・翌朝始発にも完全対応**
   - 曜日と日本の祝日（ハッピーマンデー・春分/秋分・振替休日）を自動判定して「平日 / 土曜 / 日祝」ダイヤを自動で切り替えます（ワンタップで手動切り替えも可能）。
   - 終電後は自動的に翌朝の始発電車までのカウントダウンに切り替わります。
